    登录并开启备份

    🔒 你的想法存在你自己的私有 GitHub 仓库里 —— 不经过任何服务器， 也没有别人能看到。
    每个人用自己的 GitHub 账号，就得到自己独立的一片星空。

    1. 点这个链接去生成 token（权限已经预填好了）： 打开 GitHub 生成 token →
      页面拉到最后点绿色的 Generate token 就行。
    2. 复制那串以 ghp_ 或 github_pat_ 开头的字符
    3. 粘到下面，点「登录」—— **以后这台设备都会记得你**

    🔒 token 不会明文存在本机：它用一个不可导出的密钥加密后才落地， 所以扫描浏览器存储找 token 的恶意程序拿不到东西。
    ⚠️ 但「能打开这个浏览器的人就能看到你的想法」（和没退出的邮箱一样）。 这台设备要借给别人用，请先点「退出登录」。
